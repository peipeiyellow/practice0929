# Flask Hello World 一頁式網站

這是一個基於 Python Flask 框架建置的輕量級「Hello World」一頁式網站範例。

## 專案結構

```text
practice0929/
├── app.py                 # Flask 主程式
├── requirements.txt       # 相依套件
├── templates/
│   └── index.html         # 一頁式網站前端樣板
└── README.md              # 專案說明文件
```

## 快速開始

1. 安裝相依套件：
   ```bash
   pip install -r requirements.txt
   ```

2. 啟動伺服器：
   ```bash
   python app.py
   ```

3. 開啟瀏覽器訪問：
   [http://127.0.0.1:5000/](http://127.0.0.1:5000/)
