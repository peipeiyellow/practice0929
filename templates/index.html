🛡️ SQLite 資料庫完整性約束驗證報告

本系統嚴格遵循 SQLite 關聯式架構與正規化設計，約束規範檢驗項目如下：

複合主鍵 (Composite PK) PASS

order_item 以 (order_id, product_id) 為複合主鍵，防止同一筆訂單重複加入相同商品的無效項目。

數量大於 0 約束 PASS

CHECK (quantity > 0) 約束已加入，保證訂單項目購買數量必為正整數。

單價不可為負約束 PASS

product.price 與 order_item.unit_price 皆配置 CHECK (price >= 0)，防範負數價格。

下單歷史單價保存 PASS

order_item.unit_price 保存成交當下的商品單價，未來即使商品價格調整，歷史訂單紀錄依然正確無誤。

外鍵級聯與約束 PASS

PRAGMA foreign_keys = ON; 啟用，訂單明細級聯關聯訂單主表，刪除訂單時明細自動同步。

多品項訂單案例 PASS

訂單 #1 (2項)、訂單 #2 (3項)、訂單 #3 (2項)、訂單 #4 (2項)，完全滿足多項商品訂購驗證需求。
